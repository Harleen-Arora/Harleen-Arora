# 🚀 Featured Projects

## 🔹 Telco Customer Churn Prediction

Built a machine learning project focused on solving the problem of customer churn in telecom companies. The goal was to identify customers who are likely to leave a service so businesses can take preventive actions and improve retention.

Worked with a dataset of over **7,000 customer records** and performed preprocessing, missing value handling, encoding, feature scaling, and exploratory data analysis to understand customer behavior patterns. Compared multiple ML models including Logistic Regression, Decision Tree, and KNN, where Logistic Regression achieved the best performance with **80.7% accuracy**.

This project helped me understand how real-world datasets are prepared, how ML models are evaluated, and how predictive analytics can support business decisions.

**Tech Used:** Python, Pandas, NumPy, Scikit-learn, Matplotlib

🔗 Repository:  
https://github.com/Harleen-Arora/Customer-Churn-Prediction

## 🔹 Groq UI Generator

Developed a prompt-driven UI generation tool using the **Groq API** and **Llama 3.3** model. The idea behind the project was to reduce the effort required in manually creating frontend layouts and prototypes.

The system takes a text prompt as input and generates complete HTML, CSS, and JavaScript interfaces directly inside Jupyter Notebook. It can create dashboards, landing pages, forms, and other interactive UI layouts within seconds.

Through this project, I explored API integration, prompt engineering, and dynamic frontend generation while learning how AI can assist in rapid UI prototyping and creative workflows.

**Tech Used:** Python, Groq API, HTML, CSS, JavaScript

🔗 Repository:  
https://github.com/Harleen-Arora/groq-ui-generator
